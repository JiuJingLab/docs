使用哪些權限

權限用途與資料
本機網路探索同一 Wi-Fi 的常見 TCP 端口及 Bonjour 服務，暫時處理 IPv4 位址、端口、服務名稱與類型。不讀取攝影機串流、不登入設備。
藍牙讀取附近 BLE 廣播，暫時處理名稱、系統識別碼、服務 UUID 及訊號強度。不配對、不連線。BLE 識別碼不是 MAC 位址。
相機（選用）僅在使用者啟動相機輔助檢查後，提供本機即時預覽、放大、補光及前後鏡頭切換。不拍照、不錄影、不儲存、不上傳畫面，沒有自動辨識。

不要求位置、麥克風、聯絡人或相簿權限。拒絕相機仍可使用區網與 BLE。相機在停止、離開頁面或 App 進背景時關閉，返回前景不自行啟動。

資料保存與清除

結果只在目前 App 程序記憶體中暫存，不建立磁碟掃描紀錄。按「清除」、重新開始對應掃描，或 App 程序結束後，對應結果即刪除。

App 進入背景會停止掃描；進背景不代表已清除記憶體中的結果。若你自行截圖、錄影或分享畫面，請先檢查是否包含周邊裝置資訊。App 不提供自動分享或上傳。

外部網站與問題回報

App 的原始碼與問題回報連結會在外部瀏覽器開啟 GitHub，適用 GitHub 的隱私政策。本文件網站由 GitHub Pages 提供，網站的連線紀錄依 GitHub 的政策處理；這與 App 不上傳掃描資料是不同的行為。

你可以透過 GitHub Issues 回報問題。請勿在公開 Issue 張貼私人空間、裝置識別碼、影像、密碼或聯絡資料。

未來版本

若未來加入雲端處理或帳號功能，會先更新政策，並於使用功能前說明資料用途。v0.2 不提供這些功能。
