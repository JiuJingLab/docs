開始前

揪鏡 v0.2 需要 iOS 16 或更新版本。請在自己有權檢查的空間與網路使用，確認同意開關後再開始。Wi-Fi 模式需要連上該網路；BLE 模式需要開啟藍牙。

權限或掃描沒有反應

  • 在 App「隱私」頁點「開啟系統設定」，確認本機網路及藍牙權限已允許，再重新掃描。
  • 無 Wi-Fi 或 IPv6-only 網路無法執行本版 IPv4 掃描。
  • iOS Simulator 無法驗證 BLE 硬體與本機網路權限。請使用真實 iPhone／iPad。
  • 離開 App 進入背景會停止掃描，返回後請重新開始。

怎麼看待結果

名稱、開啟端口或影像服務只是需要人工確認的線索。合法電視、家電、路由器也可能出現。名稱可偽裝，藍牙訊號強弱不代表距離。v0.2 不讀取周邊 MAC，也不猜測設備廠商。

沒有發現，不代表沒有偷拍設備。離線攝影機、隔離網路、未廣播設備、防火牆及逾時都可能造成遺漏。

辨識掃描狀態

頂部卡片顯示待確認線索及紀錄總數。有線索時可按「查看待確認線索」直接檢視原因。「掃描未完成」及「目前無法完成掃描」代表範圍、時間、連線或權限受限，不能當作沒有可疑裝置。

相機輔助檢查

在首頁下方開啟「相機輔助檢查」，按「啟動相機」並允許相機權限。可調整放大倍率（最多 4×，依鏡頭能力）、切換前後鏡頭，有補光燈的鏡頭可開啟補光。關閉或進背景會停止相機；沒有儲存或上傳畫面。

紅外線檢查指引僅協助人工觀察，不是紅外線儀器；反光與亮點不代表偷拍。Simulator 無法顯示真實相機。若權限被拒絕，可按「開啟系統設定」調整，或繼續使用 Wi-Fi／BLE。

有疑慮時

先保護自己、離開風險區域，向場地管理者確認設備用途。不要自行拆卸或破壞設備；必要時在台灣撥打 110 求助。

回報問題

請到 GitHub Issues 提供機型、iOS 版本、App 版本、重現步驟，以及預期和實際結果。截圖前請隱藏裝置名稱、IP、識別碼與個人資料。Issue 為公開內容。
