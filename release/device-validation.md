# v0.1 實機驗收

狀態：待有權測試的實體 iPhone／iPad 連線後執行。模擬器通過不表示以下已通過。

使用自己管理的測試 Wi-Fi、合法測試設備與非私人 BLE 名稱；不要對公共或鄰居網路執行掃描。

| 案例 | 預期 | 本次實機結果 |
|---|---|---|
| 首次開啟，未同意檢查 | 不觸發任何權限；開始按鈕停用 | 待測 |
| Wi-Fi 開始，允許權限 | 可發現同網路已知 TCP 服務；進度結束 | 待測 |
| 拒絕本機網路 | 顯示權限／未完成訊息，不能顯示安全結論 | 待測 |
| 設定允許後重試 | 不必重裝即可重試 | 待測 |
| 已知 RTSP 測試服務 554／8554 | 端口出現且顯示串流線索 | 待測 |
| 只有 HTTP 的已知設備 | 顯示紀錄，不判為攝影機 | 待測 |
| Bonjour RTSP、HTTP、Axis 服務 | 顯示名稱和服務類型；RTSP／Axis 命中原因 | 待測 |
| 無 Wi-Fi／IPv6-only | 說明不支援或連線不足 | 待測 |
| 訪客隔離網路／全部逾時 | 不把零結果說成安全 | 待測 |
| /30 與 /16 網段 | 不超出真實網段；大型網段顯示範圍限制 | 待測 |
| 掃描中切換 Wi-Fi／進背景 | 停止或標示未完成；沒有舊結果污染新一輪 | 待測 |
| BLE 允許／拒絕／關閉 | 各自正確顯示狀態，可停止或重試 | 待測 |
| 測試 BLE 廣播名稱 IPCAM_DEMO | 顯示名稱命中理由；RSSI 更新且同 UUID 去重 | 待測 |
| 無名稱 BLE、RSSI 127 | 顯示未知名稱／訊號，不崩潰 | 待測 |
| 停止、立即重新開始、清除 | 不混入舊回呼；清除後列表空白 | 待測 |
| 20 秒 BLE 結束 | 停止掃描，保留本次線索及限制 | 待測 |
| VoiceOver／最大字體／深色／iPad 橫直向 | 控制項可讀可操作，文字不被截掉 | 待測 |

錄影僅使用受控測試資料，影片旁白明確說明測試裝置與線索判讀，不將合成畫面當作實測證據。
